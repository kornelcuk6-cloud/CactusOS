# CactusOS

Lightweight custom Android ROM for Xiaomi Redmi 6A (cactus).

## Goals

- Fast and lightweight
- 2 GB RAM friendly
- Working calls and mobile network
- Stable Wi-Fi, Bluetooth and camera
- Clean modern interface
- Minimal bloatware

## Device

- Xiaomi Redmi 6A
- Codename: cactus
- SoC: MediaTek MT6762M
- RAM: 2/3 GB
- Android base: 10
